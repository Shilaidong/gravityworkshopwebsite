## 一、三个问题（每例只答三行）

1. **这个孩子最能讲的一件事是什么？**
   越具体越好：什么奖、什么实习干了什么、文书写的什么题、面试被问了什么……**一个点就行**
2. **最难的一关 / 我们帮他做对的那个决定是什么？**
   比如：高二先考 STEP、转赛道、砍掉保底换冲刺、文书推倒重写
3. **有没有不能写的？**
   分数、单位名、可识别线索——**不写这行 = 默认全匿名、细节照写**

## 二、怎么回答

在这个文档里直接填（每例的 1. 2. 3. 后面接着写），或者在对话里说 `5·01：……`，我代填。

**示例**——你填：

```
1. STEP 高二就考了，比同届早一年
2. 面试前模拟了六次，押对了追问方向
3. 分数可以写
```

我产出：

> **背景与条件** — 4A*，STEP II 高二完成，比常规提前一年。
> **关键判断** — 笔试硬门槛提前过线，后半程只做一件事：六轮高压模拟，
> 把「会做题」练成「会讲题」，正式面试的追问方向在射程内。

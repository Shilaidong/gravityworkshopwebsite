# v8 重构计划 —— 引力坊官网（公司官网化，视觉语言不动）

> 交接给下一位开发者。**开工前先读 [`HANDOFF.md`](HANDOFF.md)**，那里是踩过的坑。
> 本文是 2026-08-04 业主两轮校准后的定案，正在执行中。

## 依据

- **不是年刊，是公司官网**。v8 之前那版计划的年刊家具（索引/刊误/活页码/引用行）全部撤销。
- 重构范围 **ia-only**：等宽/网格/图版/打印样式等视觉语言一寸不动——它们是一寸一寸
  打出来的资产。重构的只是信息架构：栏目、首屏、命名。
- 首屏 **主张型**：一句话讲清我们是谁、为谁服务 + 明确下一步。
- Awwwards 2026 研究：主流大奖（Lando Norris / Immersive Garden / Ten Years Away）
  全是 spectacle 路线，与 `COMPANY.md` 第 10 节冲突，**不跟**；同范式的 MERSI
  （公司官网，SOTD+FWA+CSSDA+GSAP 周四杀）证明 editorial 克制路线正当打——
  它获奖靠的是"从第一屏就建立对的感知"，不是特效。
- 官网成功标准（COMPANY.md）：专业感可信、服务边界清楚、案例有说服力、联系路径无摩擦。

## A. 首屏公司门面化

- h1 主体：**引力坊 GRAVITY FANG**（公司名当主语），去「技术年刊」身份
- 主张句 + 公司元信息行（北京 · 杭州 / 中英双语 / 9:00–21:00，替掉「第 01 期」）
- CTA 进首屏：预约咨询（→§8）+ 电话 185 1973 9539
- 图版零（护照标本）保留；`<title>` / og:title / description 同步

## B. 栏目按访客意图重锚

- §1 命题 → **主张**；§2–§8 命名本就成立，保留
- 「本刊」自称全站清扫（刊头 claim、边注、§4 正文、§7 表 4、站点说明）
- 版本记录 → **站点说明**：「刊次」改「站点」，其余条目保留——这是「专业可核对」的资产

## C. 官网功能强化（内容全部出自 COMPANY.md）

- §5 **精选标记**：COMPANY.md 7.1 六例精选以黄铜 `◆` 标记（`tr[data-feat]`），
  表下口径句说明精选标准（代表不同层次、地区与方向的判断路径）
- §8 意向 select → **分段按钮**（四选项，radio + 样式化 label），触摸目标 ≥44px 不退化

## D. 签名交互：图 1 五步与回修弧联动

- hover/focus 单步时高亮它的回修关系（01/02→上弧，03/04/05→下弧），其余淡出
- **默认状态全图完整**，交互只加强调；reduced-motion、打印、无 JS 零缺失
- 这是 MERSI 式「延伸 editorial 逻辑」的一手，不是特效

## 明确不做

- 视觉语言：版式/字体/色彩/图版/打印样式一律不动
- spectacle：WebGL / 滚动劫持 / 横滚 / 鼠标跟随 / 声音 / preloader / Lenis 类库
- 年刊家具：索引、刊误、活页码、引用行（已撤销）
- 数字墙、头像卡、成功率（COMPANY.md 明令）

## 判据（每批必过）

- `node tools/cdp.mjs all` 全绿（对比度 / 四档溢出 / 降级 / 真实帧率 / 筛选 / 图加载 / 控制台）
- 打印 PDF 逐页目检（重命名波及站点说明与打印脚注）
- 375 / 768 截图目检；首屏 gzip ≤80KB 不回退
- 文案逐句核对 COMPANY.md，无编造

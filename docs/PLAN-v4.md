## 一、结构修正（最高优先级，影响已建的第一章）

**章节 = 一个持久画面背景 + 若干悬浮浅色嵌板。**

```
.chapter                position:relative
  .chap-backdrop        position:sticky; top:0; height:100vh   ← 大图 + 线描层 + 暗角，整章不动
  .chap-hero            透明，只放 13.5vw 标题与花体句
  .panel                悬浮嵌板：margin-left 270px / margin-right 22px，自带浅色底
  .panel                （可多块，中间露出背景画）
```

- 嵌板两种表面交替：**奶白 `#F6F8EB`** 与 **灰绿 `#D8D9CB`**（实测参考站就是这两种）
- 嵌板顶部接缝用现有 `[data-torn]` 生成器，底部亦可
- 左栏与顶栏已按背后底色逐块取色（`blockAt()` + `data-lt`），此改动后更关键 —— 保留
- `tonePass()` 的区块列表改为观察 `.panel` 与 `.chap-backdrop`

**需修改**：`index.html` 的 `.block/.bleed/.wrap` 体系 → 换成 `.chap-backdrop/.panel`；
第一章内容迁入嵌板。`buildTorn()`、`measureFly()`、`revealPass()`、`blockAt()` 全部复用，不重写。

## 四、案例星图（第六章主体）

21 所学校按地理分区标在一张抽象星图上。

- **分区**：英国 · 美国 · 港新 · 欧陆 · 加拿大，每区一个星座团
- **视觉**：SVG。星点亮度按层次（本科/硕博）区分，同区星点以细线连成星座
- **交互**：hover / 点击星点 → 浮出决策卡（学校、专业、层次、背景要点）
- **动效**：进入视口时星点按区依次点亮（复用 `.reticle` 的 `.on` 延迟点亮模式）
- **降级**：`prefers-reduced-motion` 直接全亮；窄屏（<720px）改为按区分组的紧凑列表，
  信息一条不少 —— 星图是增强，不是内容的唯一载体
- **可访问性**：每个星点是 `<button>`，键盘可达，`aria-label` 写全校名专业

### 出图规格（沿用样板已验证的流程）

- `mmx image generate --width 2048 --height 1152 --seed <固定>`
- **锁定风格后缀**：17 世纪学院派油画、明暗对照、暗棕与普鲁士蓝、可见画布纹理与龟裂、
  无文字无签名；**左上三分之一留深色空区给排版**
- 后期沿用 `grade.py`：暖高光/冷暗部 LUT → 统一色温 → WebP
- 线描负片降到 **560px / q45**（只在过渡瞬间低透明度出现，约 25–30KB/张）
- **AI 常伪造签名字样**，样板里已裁掉底部 4.5%；每张出图后逐一目检

### 体积预算

| 项 | 数量 | 单张 | 小计 |
|---|---|---|---|
| 章节大图 | 8 | ~40KB | 320KB |
| 线描层 | 8 | ~28KB | 224KB |
| 嵌板配图 | ~14 | ~45KB | 630KB |
| 字体 | 4 | — | 168KB |
| index.html | 1 | — | ~90KB |
| **合计** | | | **≈1.4MB** |

**首屏关键路径守住 ≤250KB**：仅 index.html + 开场大图 + 两个字重；

## 九、验证（每批都跑）

```bash
python3 -m http.server 4321
```

截图用本机 Chrome 无头模式（预览面板的截图管道在本项目不可靠，已验证）：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
  --window-size=1384,868 --virtual-time-budget=12000 --screenshot=out.png \
  "http://localhost:4321/_shot.html?y=<滚动位置>"
```

- **对比度**：全站扫描阈值 4.5:1，要求 0 缺陷；压在图上的文字另用截图像素法量真实底色亮度
- **嵌板结构**：逐帧确认左右两侧确实漏出章节大图（对照 d033/d044/d062 的像素特征）
- **帧率**：连续 120 帧采样，中位 ≥50fps
- **响应式**：375 / 768 / 1280 / 1440，无横向滚动；<1024px 左栏收抽屉
- **降级**：`--force-prefers-reduced-motion`，动效全关且**内容一条不少**
  （样板阶段踩过：整块隐藏面板会吞掉副题文案）
- **星图降级**：窄屏与降级模式下 21 条案例信息必须完整可读
- **加载**：首屏关键路径 ≤250KB；模拟慢网确认不白屏
- **控制台**：无报错

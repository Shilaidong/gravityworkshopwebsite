## 四、案例星图（第六章主体）

21 所学校按地理分区标在一张抽象星图上。

- **分区**：英国 · 美国 · 港新 · 欧陆 · 加拿大，每区一个星座团

## 十、A 批复盘（结构已定死，B/C/D 按这里走）

A 批做完后回头核对原生录屏，本计划前文有三处需要更正。**B 批动手前先读这一节。**

### 1. 嵌板只有左侧漏画面，右侧不漏

第一节表格里 d033/d044/d062 的「最右像素近黑」是**误读**——那条是浏览器滚动条：
13px 宽、列方向 σ≈1（恒定色）、上面 17px 高的亮滑块随滚动位置单调下移。
顶栏那条深色横条同样在 x=1370 收边。

实测嵌板：**左缘 x=272（≈270），右缘 x=1370 与内容区右边界齐平，内缘留白左右各 14px。**
内容区宽 1371 = 1384 − 13px 滚动条。已固化为 `--panel-x` / `--panel-pad`。

量像素**必须用原生 1384×868 帧**，`docs/ref-frames/` 是 880px 缩略图，边缘会差 2–3px。

### 2. 出图简介要改：深色空区不能留在最左

原简介写「**左上三分之一留深色空区给排版**」。那是通栏时代的要求——左边那条当时
只放左栏。改成悬浮嵌板后，**左边 270px 变成整章唯一看得见画的地方**，
再把它生成一片黑，漏出来的就只是一条黑边，不是画面，电影感直接没了。

实测：原 `b-position.jpg` 左侧 19.5% 亮度 μ=16.8，调色后 12.3，落到页面上 14.9。
参考站同一条带 μ=35–45、σ≈32。差了两倍多。

**新简介（B 批 3 张大图沿用）**：

> 画面**最左五分之一必须有清楚可辨的绘画内容**（建筑构件、帷幔褶皱、被照亮的桌沿之类），
> 亮到看得见，**不要压成一条纯黑边**；**深色空区留在画面中段偏左（横向 20%–65%）**，
> 给 13.5vw 标题当暗床。其余锁定风格后缀不变。

按新简介重出的 `position` 左带 μ=40.3 / σ=23.9（原图），落到页面 p90=52.5，
已进参考站区间。**其余 7 章按同一句改。**

配套的结构改动（已完成）：标题的暗床从 `.art-veil` 挪到 `.chap-hero::before`，
跟标题一起滚走，标题一走左边那条立刻恢复成看得见的画面。
**别再把竖向压暗加回 `.art-veil`。**

### 3. 体积预算要上调

新简介下画面细节变多，WebP 压不到原来那么小（原来 34KB 是因为大半是纯黑）。
`position.webp` 在 q58 下是 **78KB**（q52 69KB / q72 105KB；q52 与 q72
在暗部拉伸对照下肉眼无差，μΔ=1.46/255）。

章节大图预算从 8×40KB=320KB 调到 **8×78KB≈624KB**，全站合计约 1.7MB。
**首屏关键路径不受影响**（章节大图全是 `loading="lazy"`），A 批实测 169KB / 上限 250KB。
`grade.py` 默认 quality 仍是 72，出章节大图时显式给 `--quality 58`。

### 4. 规格列表不画分隔线

参考帧里那些看着像横线的，实测 σ≈60、只有五成像素暗于底色，是**文字基线不是线**。
真分隔线会是 σ≈0 的满行。所以 `.spec` 行间只留白，不描线。

### 1. 出图简介还要再狠一点：光源要点在左边

A 批那句「最左五分之一必须有可辨内容」**不够**。B 批第一轮三张里有三张不合格
（左带 μ 12.8 / 25.6 / 25.7，目标 35–45）—— 场景描述里的「一盏灯」「冷灰」
会让模型天然把光打在中间或右边，左边就成了黑洞。

**管用的写法是给左边安排一个具体光源，并用比较级下命令**：

> 画面**最左五分之一必须是整张画里最亮的区域之一**，是一块看得清、
> 可辨认的前景（中间调亮度）。左边缘绝不能是黑洞。阴影空区归到画面中部，
> 不要放在左边缘。

再配合把光源实体写进主体描述，例如「一座黄铜烛台立在画面**最左边缘**，
火苗就在画框内侧，照亮紧邻的浅色石柱与帷幔褶皱」。这样重出的两张
是 μ=42.0 / 39.4，一次过。

亮部原本在右边的那张（IV 面试）**用 `grade.py --flip` 水平镜像**即可，
不必重出。判断依据：右 19.5% 的 μ>28 且 σ>12。

### 2. 左带留亮与左栏小字会打架 —— 在流水线里解决

见 `HANDOFF.md` 4.7。要点：`grade.py` 新增 `left_rolloff()` 做最左高光压缩，
章节大图一律要做。**不要在 CSS 里给左栏文字块贴暗底垫片**，试过，是明显的补丁。

### 3. `grade.py` 新增三个开关

| 开关 | 用途 |
|---|---|
| `--flip` | 水平镜像，救亮部在右边的图 |
| `--no-left-rolloff` | 关掉最左高光压缩；嵌板配图用（不在左栏底下） |
| `--out-width` | 输出宽度，默认 1920。**嵌板配图必须给**——竖图套用 1920 会得到 1920×2400，四张画廊图白涨 400KB（146KB→24KB） |

用户对第一章的评价是"还可以的，更加丰富"。**"丰富"是可量化的差距**：
参考站开场那一屏有 **5 个抠图元素**（两个人物 + 咖啡杯 + 滑板 + 购物袋），
第一章目前只有 **2 个**。二三四章则还停在上一代——近黑暗室底图 + 单件孤立道具，
与第一章完全不是一个体系，滚下去会看到明显断裂。

## 一、每屏的元素配额

| | 参考站 | 第一章现状 | 本次目标 |
|---|---|---|---|
| 抠图元素数 | 5 | 2 | **4–5** |
| 构成 | 2 人物 + 3 现代物件 | 2 人物 | 2 人物 + 2–3 黄铜物件 |

物件**悬浮**在画面中（参考站的滑板、购物袋都是悬空的），造成刻意拼贴感。
三件通用物件（卷宗 / 行李箱 / 奖牌眼镜）**跨章复用**，只改位置尺寸与旋转——
既省出图，又让四章有共同的道具母题。

## 二、三章的画面与故事

延续「古典学者 × 现代留学生」的交会（引导 → 交接 → 并肩 → 送行）：

| 章 | 交会 | 背景 | 人物 | 悬浮物件 |
|---|---|---|---|---|
| II 档案 | 学者递卷宗，学生双手接 | 晨雾河谷，远处古典圆亭 | `fg-scholar-hand` / `fg-student-take` | 卷宗、奖牌眼镜 |
| III 文书 | 同坐一桌，各写各的 | 正午河岸，金色芦苇 | `fg-scholar-write` / `fg-student-write` | 卷宗、行李箱 |
| IV 面试 | 学者端坐发问，学生站立作答 | 晨光广场，远处列柱 | `fg-scholar-ask` / `fg-student-answer` | 行李箱、奖牌眼镜 |

**文案要跟着重写**：现有花体句与中文导语是照"暗室独坐"的调子写的
（III 章那句「凌晨最深的时刻」），与明亮外景对不上。事实仍取自 `COMPANY.md`。

## 三、每章的固定做法（第一章已验证）

1. 背景走 `grade.py --preset bg --no-left-rolloff`
2. `.chap-backdrop` 标 `data-tone="light"`，`.chapter` 标 `data-hero="light"`
3. 巨型标题翻深墨（奶白压在淡天空上只有 1.1:1）
4. `.fg-prop` **不加压暗滤镜**，全亮度
5. **两人都放右半边**，左侧留给风景（左栏目录到标题起点只有 130px）
6. 至少一个元素穿过标题词尾，只许划掉最后一到两个字母

## 四、验证

- 每章背景平均亮度 ≥150（第一章实测 204）
- 标题深墨对比度 ≥4.5:1（第一章实测 15.25:1，截图像素法量净空带）
- 抠图元素数 ≥4
- 无横向溢出 · 嵌板内文字对比度 0 缺陷 · 控制台干净 · 降级内容不丢
- 单张背景超 90KB 就降到 1600px 宽

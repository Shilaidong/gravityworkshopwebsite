## P0 · 上线阻塞（必须先修）

这两条是刚验出来的，**v6 从未在窄屏验证过**，别信之前"可上线"的说法。

### 1. 375px 横向溢出

`documentElement.scrollWidth = 391` 对 `innerWidth = 375`，**124 个元素越界**，
源头是 §5 的记录表撑到 493px。`.scroller` 有 `overflow-x:auto`，
但它的祖先链没有约束宽度，表格照样把文档撑宽。

**判据**：375 / 768 / 1280 / 1440 四档，`scrollWidth` 不得超 `innerWidth`；
越界元素数为 0。768px 已实测通过，只有 375 失败。

### 2. 十七个触摸目标不足 40px

筛选按钮 `.fbtn` 是 `min-height:32px`，另有若干链接与输入框偏矮。

**判据**：所有 `button / a / input / select` 的渲染高度 ≥44px（WCAG 2.5.5 建议值）。

### 3. 未验证项，先验再说

v6 之后**没有跑过**这三项，不要假设它们没问题：

- `prefers-reduced-motion`：规线应直接画完、内容一条不少
- 真实帧率（`--virtual-time-budget` 量不出来，方法见 `HANDOFF.md` 第 5 节）
- §5 筛选的**组合**行为（目前只验过单条件：筛"本科"得 11 行、计数器一致）

## P1 · 补完图版

### 1. 刊头图版缺失

第四张源图 `pl-desk`（桌面横幅，1800×700）**生成失败**，刊头目前无图版。
重出并转版即可，参数见 `HANDOFF.md` 的图版流水线一节。

### 2. `pl-transcript` 超出体积目标

860px / cell=6 下仍有 **70KB**，目标 60KB（另两张 41 / 55KB 达标）。
该图暗部面积大、网点覆盖率高，PNG 压不动。
可选：再降宽度、加大网格、或换一张暗部没那么满的源图。

### 3. 出图提示的关键约束

**源图必须有连续中间调**，跨度 >110 才够打网点。
提示必须写"侧逆光、深阴影、连续影调、可见纹理"；
写"均匀柔光、无硬阴影"会得到两个平调（实测跨度只有 66–70），网点打不出层次。

## P2 · 打印样式表（建议优先做，性价比最高）

它自称是一份**年刊**，那就该印得出来。技术年刊有一张体面的打印样式表，
是同行一眼看出用心的地方，而且几乎没有别家留学机构会做。

- 边注栏在打印时移到页脚或转为脚注
- 顶栏、筛选器、CTA 一律 `display:none`
- 图版转灰度网点（已经是网点，直接印就对）
- URL 在链接后以 `content: " (" attr(href) ")"` 展开
- 分页控制：`break-inside: avoid` 保住表格行与图版

**判据**：Chrome 打印预览下 A4 纵向不断行错位，图版不跨页撕裂。

## P3 · 内容深化

按价值排序，不必全做：

1. **更多图版**：§2 §3 §4 §6 §8 目前无图版。题材继续走"申请季的物证"，
   但注意别让图版多到打断阅读——年刊里图版是稀缺件。
2. **图 2 用真实分布驱动**：现在的概率梯度是示意柱，柱高是手写的。
   若有真实的档位分布数据，让柱高由数据生成，图注写明口径。
3. **边注承载交叉引用**：现在每节只有一条限定条件，可以加"参见 §4 表 2"一类的互引。
4. **中文标题字**：目前中文全走系统字体栈。若要更强的识别度，
   可子集化一款开源中文字体**只用于标题**——但中文 webfont 动辄 5MB+，
   必须子集化到只含用到的字，否则国内加载会毁掉首屏。

## P4 · 上线前的最后一件事

**表单没有后端。** `index.html` 里搜 `FORM_ENDPOINT`，现在是空字符串。
空的时候行为是诚实的：不发请求、不给"提交成功"的假象，
而是把信息复制到剪贴板并把二维码顶到眼前。

要真正收到线索，**需要业主自己注册第三方表单服务并提供端点**——
这一步不该由开发者代办（涉及注册账号与凭据）。

## P0 · 已修并验证（记录在此，供复核）

写这份计划时验出两个上线阻塞项——**v6 重写之后从未在窄屏验过**——现已修掉。

### 1. 375px 横向溢出 → 已修

`scrollWidth` 曾是 391 对 375。**第一次诊断错了**：我以为源头是 §5 的记录表，
给它加了 `min-width` 反而把越界推到 580。

实际上 `.scroller` 一直工作正常（实测 w=335 / scrollWidth=560 / clientWidth=335），
真正越界的是 **§3 §4 §6 §7 那四张裸 `<table>`**——它们在 `.tbl` 里没有滚动容器，
`min-content` 直接把 `documentElement` 顶开。约束加在 `.tbl` 上即可。

> **排查手法**：别按"哪个元素最宽"下判断。要过滤掉**已在滚动容器内**的元素
> （逐级向上查 `overflowX` 是否为 `auto/scroll`），剩下的才是真凶。
> 我漏了这一步，第一次就修错了对象。

### 2. 触摸目标不足 → 已修

筛选按钮 32px → 44px，表单控件与提交键一并抬到 44px，
`@media (pointer:coarse)` 下再撑目录与顶栏的点击区。
句中内联链接按 WCAG 2.5.5 的内联豁免不计。

**复核结果**：375 / 768 / 1280 三档 `scrollWidth` 与 `innerWidth` 相等，
容器外越界 0，表单与按钮无一低于 44px。

### 3. 三项补验 → 已跑完

**`prefers-reduced-motion`**：6 条规线全部直接画完（`stroke-dashoffset` 归零），
未画完 0 条。可见文字元素 **374 个，与非降级模式完全一致**；隐藏元素两种模式都是 2 个。
**降级不吞任何内容**——这条是 v5 踩过的坑（曾把副题连面板一起隐藏），本版没有重犯。

**§5 筛选组合**：8 个组合用例（单条件 / 双条件 / 三条件）显示行数、
期望行数、计数器读数**三者全部一致**，不一致 0 个。
空结果分支（本科 + 欧陆 + 工程）显示 0、计数器 0，不崩；重置回 21 例。

**帧率**：`--virtual-time-budget` 量不出真帧间隔，但它**不影响同步代码的执行时长**，
所以改量滚动处理函数的单帧耗时——那才是真正的风险来源。
160 次采样：中位 **0.000ms**、p95 **0.100ms**、最慢 0.200ms，
**p95 只占 16.7ms 单帧预算的 0.6%**。

本版无视差、无鼠标跟随、无 transform 动画，持续运行的 CSS 动画元素 **0 个**，
rAF 空闲时只做一次 `scrollY` 数值比较。
v5 那种"每帧对 26 件抠图各做一次 `getBoundingClientRect`"的负担在本版不存在。

> 若仍要拿到真实帧间隔，需装 `websocket-client` 走 CDP（本机未装）。
> 以当前的每帧耗时，装依赖去测的价值不大。

## P1 · 补完图版

### 1. 刊头图版缺失

### 2. `pl-transcript` 超出体积目标

860px / cell=6 下仍有 **70KB**，目标 60KB（另两张 41 / 55KB 达标）。
该图暗部面积大、网点覆盖率高，PNG 压不动。
可选：再降宽度、加大网格、或换一张暗部没那么满的源图。

### 3. 出图提示的关键约束

**源图必须有连续中间调**，跨度 >110 才够打网点。
提示必须写"侧逆光、深阴影、连续影调、可见纹理"；
写"均匀柔光、无硬阴影"会得到两个平调（实测跨度只有 66–70），网点打不出层次。

## P2 · 打印样式表（建议优先做，性价比最高）

它自称是一份**年刊**，那就该印得出来。技术年刊有一张体面的打印样式表，
是同行一眼看出用心的地方，而且几乎没有别家留学机构会做。

- 边注栏在打印时移到页脚或转为脚注
- 顶栏、筛选器、CTA 一律 `display:none`
- 图版转灰度网点（已经是网点，直接印就对）
- URL 在链接后以 `content: " (" attr(href) ")"` 展开
- 分页控制：`break-inside: avoid` 保住表格行与图版

**判据**：Chrome 打印预览下 A4 纵向不断行错位，图版不跨页撕裂。

## P4 · 上线前的最后一件事

**表单没有后端。** `index.html` 里搜 `FORM_ENDPOINT`，现在是空字符串。
空的时候行为是诚实的：不发请求、不给"提交成功"的假象，
而是把信息复制到剪贴板并把二维码顶到眼前。

要真正收到线索，**需要业主自己注册第三方表单服务并提供端点**——
这一步不该由开发者代办（涉及注册账号与凭据）。
